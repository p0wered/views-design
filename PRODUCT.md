# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Человек, которому нужен займ у МФО. Он открывает витрину, чтобы сравнить готовые предложения и уйти на сайт выбранной организации. Состояние: спешка, сравнение цифр, низкое доверие к «яркому финтеху».

Вторая аудитория: команда, которая выбирает визуальный вариант витрины среди маршрутов `/design-1` … `/design-10`.

## Product Purpose

Показать актуальные офферы партнёров и дать переход на сайт МФО. Сайт сам займы не выдаёт. Успех для посетителя: понял условия и кликнул CTA. Успех для галереи: несколько различимых раскладок на одних данных.

## Positioning

Одна витрина, живые офферы ClickLead, несколько равноправных дизайнов. Соседний лендинг МФО показывает свои продукты; эта поверхность сравнивает чужие офферы и честно отправляет человека дальше.

## Operating Context

Маршруты `/design-1` … `/design-10` (алиасы `/1` … `/10`). Данные: `POST https://api.click-lead.ru/offers?v=2.0`. Сортировка: по умолчанию, по сумме, по сроку. Юридический футер общий. Оценка идёт в браузере на десктопе (~1440) и мобильном (~390).

## Capabilities and Constraints

Есть в API и можно показывать: логотип, имя, `max_loan`, `loan_length_max`, `percentage`, `approved_age_min`, `link`, флаг `is_first_nopercentage`.

Нельзя выдумывать: минимальную сумму, процент одобрения, рейтинг, отзывы, «предодобрение», если этого нет в ответе.

Общее для всех дизайнов: Vue 3 + Vite + Tailwind 4, `lucide-vue-next`, состояния загрузки / ошибки / повтора, CTA высотой около 48 px, фокус с клавиатуры, `prefers-reduced-motion`.

Дизайны 6 и 7: ровная сетка одинаковых карточек. Не рескин design-3. Светлая тема. Без игрового неона и финтех-хайпа. Акценты не синий, не бирюза, не индиго, не оранжевый, не лайм.

Дизайны 8–10: три продакшн-кандидата на тех же данных. 8 светлый разворот, 9 светлое расписание по строкам, 10 светлая сетка одинаковых карточек. Без героя как единственного оффера. Новые акценты, не повторяющие 1–7.

## Brand Commitments

Голос прямой, без рекламных усилителей. Юридические абзацы футера не переписывать. Светлая галерея. Доверие важнее зрелищности.

## Evidence on Hand

Живые офферы и логотипы из ClickLead. Макеты 1–3 в `design-references/`. Реализации 1–10 в `src/views/DesignOne.vue` … `DesignTen.vue`. Референс сетки карточек: design-3 и `monetza-ru` (`Card.vue`, сетка в `Companys.vue`).

## Product Principles

1. Только факты из API: недостающее поле не заполняется «для красоты».
2. В сетке все карточки одного ранга: человек сравнивает, а не ищет героя.
3. CTA ведёт на сайт МФО, это не заявка внутри витрины.
4. Светлая поверхность и спокойный акцент; зрелищность не должна спорить с цифрами.

## Accessibility & Inclusion

Контраст текста WCAG AA. CTA и сортировка доступны с клавиатуры. Учитывается `prefers-reduced-motion`. Витрина должна читаться на узком телефоне без горизонтального скролла.
